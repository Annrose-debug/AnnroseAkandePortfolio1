✿ About Me ✿

Hi, I'm Annrose Akande — a computer programming graduate and software developer focused on building full-stack applications, while also bringing a strong foundation in technical support and data analysis. I love tackling tech problems from different angles: coding a feature, debugging a broken system, or writing SQL queries to pull backend data insights.

Here's a quick look at my core toolkit:

  • Software Development — hands-on with JavaScript, React, Next.js, Node.js, and Java, Python. I've built web dashboards, e-commerce interfaces, and full-stack apps with REST APIs and secure authentication.
  • Technical Support — system troubleshooting, diagnosing software errors, managing documentation, and keeping things running.
  • Data & Databases — working with MySQL — structuring data, writing efficient queries, and analyzing backend datasets to track metrics.

I've collaborated with teams at Bliss & Giggles and Kinplus Technologies to improve UI/UX, optimize system performance, and deliver reliable technical solutions. Right now, I'm building and documenting a full-stack Job Application Tracker using React, Node.js, and MySQL — sharing progress daily as a way to push my frontend and backend skills together.

I'm actively seeking entry-level opportunities across Software Development, Technical Support, and Data Analyst roles where I can dive in, solve problems, and keep growing.

How I got here

✿ My Story ✿

where the wires actually are

Started in IT support

Before I wrote a line of front-end code, I was the person fixing the printer, resetting the router, and figuring out why the Wi-Fi dropped mid-meeting — as a Full Stack Developer at Bliss & Giggles and an IT Support Specialist at TD Place. That hands-on troubleshooting instinct — diagnose first, don't guess — is still how I approach every bug I hit today.

formal foundation

Enrolled in Computer Programming, Algonquin College

Ottawa. This is where the IT-support instincts got structure: data structures, databases, networking theory, and enough Java and Python to stop treating code like a black box. Graduated April 2026 with a much clearer picture of how the whole stack — hardware to UI — actually fits together.

first real ships

Building full-stack apps, end to end

This is where "it works on my machine" turned into "it works," full stop. I built RoomieLink, a web app that matches students with compatible roommates, using HTML, CSS, JavaScript, a database, and a full authentication system — and a Job Application Tracker that lets users log in and out securely with JWT tokens while it tracks their applications. This is where I fell for the craft side of the full stack: auth flows that actually hold up, layouts that adapt, and the small details that make an app feel considered.

main

Building across the full stack, today

Now I move deliberately between domains — segmenting enterprise networks, working with cloud infrastructure, tuning relational schemas, and shipping React interfaces — because I think the most useful engineers are the ones who understand the whole path a request takes, not just their one layer of it. Outside of that, I write on Substack about the parts of being human that code can't fix.
